Start with [DailyXP](https://github.com/da5ater/dailyxp) for my desktop application work.

## Selected projects

### [DailyXP](https://github.com/da5ater/dailyxp)

A Linux desktop application that brings focused work, goals, habits, and recovery into a life gamification system. Built around Omarchy, with an Electron desktop app and an optional shell companion.

### [AnkiHelper](https://github.com/da5ater/AnkiHelper)

Capture study notes through dictation, text, or screenshots, then review AI-assisted flashcards and import them into Anki through AnkiConnect. Built in Python, with support for several coding agents.

### [Build Your Own X](https://github.com/da5ater/byox)

A Claude Code workflow that turns a transcript, repository, or article into a local programming course, with exercises you implement step by step.
